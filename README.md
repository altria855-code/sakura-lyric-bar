# 字幕栏 · Sakura Lyric Bar

**把角色说的话像歌词一样贴在桌面上。**

全屏看视频时也能看到对话,不必为了看一眼台词切回窗口;不需要立绘的场合,也不用让它一直占着画面。

![浮窗截图](screenshots/bar.png)

> 这是一个 [Sakura](https://github.com/Rvosy/Sakura) 插件(Plugin API v4)。

## 它做什么

在桌面上开一个**始终置顶、可拖动**的小浮窗:

- 显示当前角色正在说的台词,日文原文与中文译文**双语对照**(可切只中文 / 只日文);
- **正在朗读的那一句会高亮**,跟着语音一句一句往下走;长台词在栏内自动滚动跟随;
- 鼠标移到浮窗上 → 出现输入框 → 点击、打字、**回车直接把消息发给角色**;
- 外观全部可以在插件设置里调:字号、字体、文字颜色、背景色、背景不透明度、整体不透明度、圆角、边框、文字描边与阴影;
- 拖动后的位置会被记住(含多屏)。

## 安装

1. 到 [Releases](../../releases/latest) 下载 `字幕栏.zip`;
2. Sakura → **设置 → 插件 → 更多 → 从 ZIP 安装…**;
3. 在插件列表里找到「字幕栏」,打开**启用**开关;
4. 点设置页底栏的**应用**或**保存并关闭**。

浮窗会出现在主屏下方居中。详细设置说明见 [`docs/settings.md`](docs/settings.md)。

## 已知限制

- **仅 Windows**。用到的是 Win32 的分层窗口与 GDI,没有跨平台实现。
- **独占全屏的游戏之上看不见它**(无边框窗口化 / 全屏窗口化正常)。独占全屏会绕过桌面合成,所有普通窗口都画不上去 —— 歌词类软件同理。出于反作弊风险考虑,没有采用注入游戏渲染管线的方式。
- **「全屏应用时自动隐藏」默认开启**:检测到全屏程序会把浮窗藏起来(为游戏场景设计)。如果你主要在**全屏看视频时**用它,请到插件设置里把这个开关**关掉**。
- **用浮窗打字发出的消息,角色的回复不会被朗读**(只有字幕)。这是宿主侧的限制:语音播放由桌面端原生层驱动,而它只驱动自己发起的对话;插件走的 `sakura.host.mobile` 通道拿不到驱动语音所需的内部标识。已向宿主提交 [issue #227](https://github.com/Rvosy/Sakura/issues/227)。**想听声音时在主窗口说话即可,浮窗照样显示字幕。**
- 输入框在低「背景不透明度」下文字会一起变淡(原生输入框无法只让背景透明)——把背景不透明度调到 100 即可让它变实心。
- 字体列表来自系统注册表,个别名字可能无法实际渲染。

## 开发

源码在仓库根目录,是零第三方依赖的纯标准库实现(用 `ctypes` 直接调 Win32)。

```bash
# 跑测试(205+ 用例,含契约测试)
python -m unittest discover -s tests -v

# 不启动 Sakura,单独跑浮窗看效果
python overlay.py --demo
```

几个模块的职责:

| 模块 | 做什么 |
|---|---|
| `theme.py` / `layout.py` | 配置投影;台词分句 → 渲染行 → 栏内布局 |
| `compose.py` / `raster.py` / `win32.py` | 像素合成(预乘 BGRA)、GDI 覆盖度光栅化、Win32 绑定 |
| `canvas.py` / `inputbox.py` | 画布窗口(置顶/拖动/悬停)、原生输入框(输入法) |
| `fullscreen.py` | 全屏应用检测 |
| `overlay.py` / `protocol.py` | 浮窗主循环与两进程间的 JSON 行协议 |
| `hostlink.py` / `timeline_source.py` / `sender.py` / `highlight.py` | 插件侧:进程管理、台词读取、发送、高亮推进 |
| `plugin.py` | 插件入口接线 |

设计文档见 [`docs-design.md`](docs-design.md)。
