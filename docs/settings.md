# 字幕栏

把角色的台词像歌词一样显示在桌面浮窗上:**当前正在朗读的那一句会高亮**,长台词在栏内自动滚动跟随;鼠标移到浮窗上会出现输入框,可以直接打字发消息给角色。

## 安装

1. 打开 Sakura **设置 → 插件 → 更多**。
2. 选 **从 ZIP 安装…**,选中 `字幕栏.zip`;已经解压出源码时,也可以选 **从文件夹安装…** 并指向 `plugin` 文件夹(如 `D:/work/sakura-lyric-bar/plugin`)。
3. 在插件列表里找到「字幕栏」,打开**启用**开关。
4. 点设置页底栏的 **应用** 或 **保存并关闭**。浮窗随即出现在主屏下方居中。

## 怎么用

- **拖动**:按住浮窗空白处拖动,位置会被记住。
- **打字**:鼠标移到浮窗上出现输入框 → 点击聚焦 → 回车发送;按 Esc 收起输入框(没发出去的**草稿会保留**,移回去可以继续写)。回复进行中不能再次发送,会提示「还在回复中」。

## 设置

入口:**设置 → 插件 → 选中「字幕栏」→ 插件设置**。设置分「显示 / 颜色与材质 / 行为」三组。

### 显示

| 设置项 | 含义 | 取值(默认值) |
|---|---|---|
| 显示模式 | 台词显示哪种语言 | 双语 / 中文 / 日文(双语) |
| 字体 | 台词字体;选项来自系统已装字体,中/日文字体排在前面 | 最多 64 项(Microsoft YaHei UI) |
| 字号 | 文字大小 | 10–72(20) |
| 栏宽 | 浮窗宽度,单位像素 | 200–1600(460) |
| 最多显示行数 | 栏内最多显示几行,超出后栏内滚动跟随当前句;此处「行」指渲染行,双语模式下每句占两行 | 2–40(10) |
| 行距 | 行高 = 字号 × 行距 | 1.0–3.0,每次 0.05(1.35,高级) |

### 颜色与材质

颜色字段都要**手填十六进制**(设置页没有取色控件),支持两种写法:

- `#RRGGBB`,如 `#FFFFFF` 是白色;
- `#AARRGGBB`,前两位是透明度,如 `#80000000` 是半透明黑;`00` 全透明、`FF` 不透明。

| 设置项 | 含义 | 默认值 |
|---|---|---|
| 原文颜色 | 日文原文的文字颜色 | `#FFFFFF` |
| 译文颜色 | 中文译文的文字颜色 | `#CFCFCF` |
| 当前句文字颜色 | 正在朗读的那一句的文字颜色 | `#FFD400` |
| 当前句底色 | 当前句背后的底色;**留空表示不填底色** | 空 |
| 背景色 | 浮窗背景的颜色 | `#0E0E12` |
| 背景不透明度 | 背景有多不透明;调到 0 就是全透明 | 0–100(65) |
| 整体不透明度 | 整个浮窗(含文字)有多不透明;与「背景不透明度」互相独立,背景变淡时文字清晰度不受影响 | 0–100(100) |
| 圆角半径 | 浮窗四个角的圆角大小 | 0–40(14) |
| 边框粗细 | 浮窗外框的线宽,0 表示不画边框 | 0–4(0) |
| 边框颜色 | 外框颜色 | `#FFFFFF` |
| 文字阴影 | 给文字加一层阴影,便于压在亮色背景上 | 开 |
| 文字描边粗细 | 文字描边的线宽,0 表示不描边 | 0–3(0) |
| 文字描边颜色 | 描边颜色 | `#000000` |

### 行为

| 设置项 | 含义 | 取值(默认值) |
|---|---|---|
| 显示浮窗 | 关掉后浮窗立刻消失(配置保留),适合临时不想看到它 | 开 |
| 没内容时收起成小条 | 没有台词时收成一条细条,鼠标移上去仍能唤出输入框打字;关掉则整窗隐藏,等下一句台词出现 | 开 |
| 高亮跟随方式 | **跟随语音**按朗读逐句推进;**按字数估算**不依赖语音、按字数估算节奏;**不高亮**始终不高亮 | 跟随语音 / 按字数估算 / 不高亮(跟随语音) |
| 全屏应用时自动隐藏 | 前台是全屏程序时整体隐藏浮窗,退出全屏后原样恢复 | 开 |
| 鼠标移开后收起延时 | 鼠标离开浮窗后,输入框延迟多久收起(毫秒) | 200–3000(800,高级) |
| 浮窗状态 | 只读。「运行中」或「未运行」,未运行时附上最近一次的原因 | — |
| 当前位置 | 只读。记住的位置显示为「屏幕名 (x, y)」;还没记住则显示「默认位置」 | — |

### 三个按钮

| 按钮 | 作用 |
|---|---|
| 预览效果 | 在浮窗里放一段示例台词,用来试外观;不改动任何设置,也不影响当前对话 |
| 回到默认位置 | 清掉记住的位置,浮窗回到主屏下方居中 |
| 重新启动浮窗 | 浮窗没在运行就启动它;正在运行就重启它(卡住时用) |

## 保存时机(重要)

在设置里改完字段后点 **完成**,只是记住了草稿,**还没有生效**;必须在设置页底栏点 **应用** 或 **保存并关闭**,改动才会真正提交,浮窗随即变化(不需要重启插件)。

点 **取消**、右上角关闭或按 Esc,会恢复成打开设置窗口时的值。三个按钮(预览效果等)则是一点就执行。

## 改了源码之后

改动 `plugin` 文件夹里的 `.py` 后,**必须在插件页重新安装一次这个文件夹**(或重新安装 ZIP),运行的才是新代码;只重启插件不会生效。

## 位置记在哪里

拖动后的位置存在 Sakura **数据目录**下本插件的数据目录里:

```
data/plugins/local.sakura.lyric-bar/state.json
```

注意是数据目录,不是插件的安装目录。删掉这个文件等同于「回到默认位置」。若记住的屏幕已经不存在(拔掉显示器、改了分辨率),浮窗会自动回到主屏下方居中。

## 查看日志

- Sakura 的**运行日志窗口 →「插件」页**,可按插件筛选;
- 文件位于 `data/logs/sakura-plugins.log`(约 10 MiB 轮转,保留 5 个备份);
- 安装、加载失败一类宿主诊断在 `data/logs/sakura-runtime.log`,排障时可能需要同时看两份。

## 已知限制

- **用浮窗打字发出的消息,角色的回复不会被朗读**(只有字幕显示)。原因在宿主一侧:语音播放由桌面端原生层驱动,而它只驱动桌面窗口里发起的对话;浮窗走的插件通道拿不到驱动语音所需的内部标识。**想听声音时在 Sakura 主窗口里说话即可**;打字时看字幕。


- 仅支持 Windows。
- **游戏显示模式决定浮窗能否显示**:无边框窗口化 / 全屏窗口化下浮窗正常可见并跟读;**独占全屏(Exclusive Fullscreen)下所有普通窗口都画不上去**,浮窗必然不可见(歌词类软件同样如此)。不采用注入游戏渲染管线的方式(反作弊风险),所以独占全屏时唯一的做法是自动隐藏(见「全屏应用时自动隐藏」)。
- 常驻置顶窗口可能让部分独占全屏游戏无法进入全屏优化模式,「全屏应用时自动隐藏」默认开启正是为此。
- **字体名来自系统注册表,个别名称可能无法实际渲染**:注册表里的名字常是合并名或带样式词,而真正可用的字体名是单一家族名,传错名字时会静默回落到默认字体(画面不变、也不报错)。若发现选了字体却看不出变化,先在别的程序里确认这个名字能选中。
- **任务栏设为「自动隐藏」时会误判**:此时最大化任何普通窗口都会被当成全屏,浮窗被隐藏。缓解办法:把任务栏改成常显,或在设置里关掉「全屏应用时自动隐藏」。
- 输入框为单行,不支持 Shift+Enter 换行。
- 输入框文字在低不透明度下会偏淡:输入框整体跟随「背景不透明度」变淡,里面的文字也会一起变淡。想让输入框清晰,把「背景不透明度」调到 100。
- 颜色需手填十六进制(设置页没有取色控件)。
- 字体候选上限 64 个;新装的字体要等插件重新加载后才会出现在列表里。
- 只显示最新一条回复,不提供历史回看。
- 发送不排队:回复进行中再回车会被拒绝,提示「还在回复中」。
- 关闭 Sakura 后浮窗随即消失(浮窗依附于插件进程存活)。
